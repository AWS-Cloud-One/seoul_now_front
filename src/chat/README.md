# 기본 채팅·추천 모듈

`chat-v2/` 실험 모듈을 `chat/`으로 통합했습니다. `AppShell`의 AI 추천·AI 대화·저장 화면에서 이 모듈을 사용합니다. 별도 활성화 옵션이나 이전 채팅으로 전환하는 분기는 없습니다.

- `components/`: 입력창, 진행 상태, 질문 선택, 추천 카드, 추천 조건 폼, 저장 목록.
- `state/`: 서버 요청 추적·취소·복구, 대화 복원, 추천 묶음 저장.
- `api/`: `/api/v2/chat` 계약과 클라이언트. `mockClient`는 테스트·화면 작업 전용.
- `model/`: 응답 라벨, 질문 연결, 결과 참조.
- `chat.css`: 모듈 스타일. 공통 화면 조정은 `styles/ux-refinements.css`.

## 연결

| 설정                 | 기본값                  | 의미                           |
| -------------------- | ----------------------- | ------------------------------ |
| `VITE_CHAT_MODE`     | `real`                  | `mock`을 명시할 때만 모의 응답 |
| `VITE_CHAT_BASE_URL` | `/api/v2/chat`          | 브라우저가 호출하는 채팅 API   |
| `CHAT_PROXY_TARGET`  | `http://127.0.0.1:8001` | Vite 개발·미리보기 프록시 대상 |

서버 API 버전은 바꾸지 않습니다. 기존 대화를 복원하기 위해 `bgsj.chatV2.v1:<mode>:<baseUrl>` 키와 추천 저장 키도 유지합니다. URL·빌드 모드가 달라지면 별도 세션입니다. 배포에서는 정적 호스팅의 API 연결도 준비되어 있어야 하며, 이 작업은 로컬 화면 통합입니다.

## 이번 화면 정리

- 홈 이름은 밖과사전. 혼잡 자료 미확인 안내는 닫기·재조회 가능한 스낵바로 보여주고, 상단 상태와 자료 유의사항은 유지합니다.
- 지도 위의 출발지 설정과 시작 시 위치 권한 요청을 제거했습니다. 혼잡 정렬은 지도 중심 기준이며 출발지는 채팅·길찾기 등 필요한 화면에서 받습니다.
- 실행 중 입력창의 전송 버튼을 중지 버튼으로 교체합니다. 접수 전·접수 여부 미확인 상태는 중지를 비활성화하고, 서버 실행 ID를 받은 뒤 해석·조회 중에 취소합니다. 중지 요청 후에도 서버 결과를 확인합니다.
- 이전 형식 저장본은 읽기 전용으로 보여줍니다. 현재 추천에 이전 조건을 덮어쓰거나 이전 채팅 API를 다시 실행하지 않습니다.

기본 앱의 연결 검증은 `src/__tests__/recommendationFlow.test.tsx`, 상세 채팅 상태 검증은 이 모듈의 테스트에 있습니다. 이전 UI만 전제하던 통합 검사는 현재 기본 흐름으로 교체했고, 이전 API·저장 데이터의 단위 검사는 유지합니다.

## 로컬 확인 (2026-11-13)

테스트 180건, lint, TypeScript 검사와 빌드가 통과했습니다. Playwright에서 모바일 화면의 혼잡 스낵바·닫기·상단 상태 유지, 기존 대화 복원, 실제 로컬 API의 해석 중 중지와 전송 버튼 복귀를 확인했습니다. 빌드의 기존 500 kB 청크 경고는 남아 있습니다. AWS 배포·커밋·푸시는 하지 않았습니다.
