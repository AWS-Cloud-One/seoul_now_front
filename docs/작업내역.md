# 지도·서울 데이터 화면 작업 내역

- 카카오 지도·장소 검색·자동차 길찾기 화면을 연결했습니다.
- 주변 주차장과 총면수·요금·운영시간 원본 상세를 표시합니다.
- TOPIS 도로망과 도시데이터 주변 도로를 선택해서 볼 수 있습니다.
- 행정동 경계와 실제 121장소 혼잡도 관측 영역을 구분합니다.
- S-DoT 지점 통행량과 CCTV 위치·단일 영상 재생 기능을 추가했습니다.
- Windows Docker의 변경 감지와 키 전달 설정을 보완했습니다.
- TypeScript/Vite 빌드와 변경 파일 ESLint를 통과했습니다.

실제 .env.local은 포함하지 않았습니다. .env.example을 참고하여 JavaScript 키를 로컬에 입력하세요.
백엔드 main의 신규 API가 필요합니다. 주차 자료는 부분 수집이며 영상 제공처·브라우저에 따라 CCTV 재생이 제한될 수 있습니다.
